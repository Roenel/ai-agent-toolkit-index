## 3. Duplicate clusters → best pick

| Cluster | Members | Best pick | Why |
|---|---|---|---|
| Cline lineage (VS Code agents) | Cline, Roo Code (archived), Zoo Code (fork), Kilo Code (extension) | **Cline** | Original upstream and actively maintained. Roo is dead, Zoo is community-only, and Kilo's CLI is really OpenCode |
| OpenCode lineage (open TUI CLIs) | OpenCode, Kilo CLI (fork) | **OpenCode** | Upstream, MIT, and `--auto` is opt-in. Kilo adds a platform layer on top |
| Vendor-locked terminal agents | Codex, Claude Code, Gemini CLI, Antigravity CLI, Grok Build, Cursor CLI, Amp | **Codex CLI** as the reference harness | Apache-2.0 source with the safest defaults: OS sandbox on, network off, OTel off. Claude Code has the richest plugin ecosystem but is proprietary and defaults to auto mode |
| Google pair | Gemini CLI vs Antigravity CLI | **Gemini CLI** for the library | Open source (Apache-2.0) with documented defaults. Antigravity has no license and collects interactions data by default |
| Skill format (`SKILL.md` + YAML frontmatter, Agent Skills standard at agentskills.io) | openai/skills (deprecated), anthropics/skills, gemini-skills, cline/skills, Amp skills, Cursor plugin skills | **anthropics/skills** for spec + examples; **openai/plugins** for Codex packaging | Same format everywhere. Anthropic hosts the spec and template. Amp loads `.claude/skills` natively and Cline installs via `npx skills` |
| Plugin/marketplace manifests | `.claude-plugin/`, `.codex-plugin/`, `.cursor-plugin/`, Cline `entry.json`, Gemini extensions | **Claude plugin format** as the import source | Cursor's plugin repo already ships `.claude-plugin/`. Formats are close but not identical, so plan a converter |
| Project instructions | `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursor/rules/*.mdc`, `AGENT.md` (Amp, older), `.goosehints` | **AGENTS.md** | Open spec (MIT, has a charter) and the default for Codex/Goose/Cursor/Grok. ## 4. Top safety flags

1. **Goose `GOOSE_MODE=auto` by default**, with no OS sandbox.
2. **Cline CLI `--auto-approve` defaults to true, and telemetry is on by default.**
3. **Amp: allow-all permissions and unmatched MCP servers allowed by default**, plus auto-updates.
4. **Claude Code interactive sessions default to `auto` (classifier) mode, and metrics telemetry is on by default** on the Claude API.
5. **Grok Build and Gemini CLI: sandbox off by default** (Gemini enables it only under YOLO). Gemini also defaults usage statistics on.
6. **Antigravity CLI collects Interactions data by default** and has no license file.
7. **Cursor `-p` has write and shell access.** `--yolo`/`--force` plus `--trust` gives an unattended run with no workspace prompt.
8. **Aider `--yes-always` also accepts the analytics opt-in**, and the repo has been stale for about 6 months.
